Quello che abbiamo imparato

Le tecnologie che abbiamo scoperto

Chiara Imola ci ha introdotto al suo stack quotidiano. Ecco gli strumenti e i concetti che abbiamo toccato con mano in questi giorni.

REST API
I servizi web RESTful sono l'interfaccia tra i componenti software: il client invia una richiesta HTTP, il server risponde con dati JSON. Chiara li usa ogni giorno nel suo lavoro.
HTTP · JSON · GET/POST
Maven
Il tool di build per Java che abbiamo visto usare da Chiara: gestisce le dipendenze del progetto, compila il codice ed esegue i test con un unico comando mvn test.
Build · Dipendenze · Java
Testing del codice
Martedì abbiamo assistito al collaudo di una funzione Testbook: si scrivono i casi di test prima ancora del codice (TDD). Il sistema verifica automaticamente che ogni funzione produca l'output atteso.
TDD · Unit Test · Testbook
Java
Il linguaggio del nostro esercizio. Abbiamo implementato la logica del calcolatore ore — divisioni intere, modulo, cicli — come fanno i developer in produzione, poi l'abbiamo portata in JavaScript per il web.
OOP · Backend · JVM
Microservizi
NTT Data costruisce applicazioni come insiemi di servizi indipendenti che comunicano via API. Ogni servizio ha un compito preciso: più facile da testare, scalare e aggiornare.
Architettura · Scalabilità
Metodologie Agile
I professionisti di NTT Data lavorano in sprint brevi, con daily stand-up e retrospettive. Abbiamo capito come si organizza un team di sviluppo vero in modo da consegnare valore ogni settimana.
Scrum · Sprint · Kanban
Cosa abbiamo fatto martedì

Simulatore di collaudo del codice

Martedì abbiamo testato funzioni Java e osservato come un tester verifica il comportamento del codice. Riprova tu stesso: rispondi alle domande come farebbe un QA engineer.

CalcolatoreOre.java
public class CalcolatoreOre {
  // Ore lavorative per giorno
  static final int ORE_GIORNO = 8;

  public static int giorniLavorativi(int oreT) {
    return oreT / ORE_GIORNO;
  }

  public static int oreRimanenti(int oreT) {
    return oreT % ORE_GIORNO;
  }

  public static double oreRuolo(int oreT, double quota) {
    return oreT * quota;
  }
}
